Sensitive values stored AES-256-GCM encrypted in the daemon DB. Reference them from the DSL with env: VAR: secrets(name) (mounts the value as a file at /run/secrets/<name>) or secrets: [name] (file mount). Only the content hash is shown by default — use Reveal to decrypt a value on demand.
